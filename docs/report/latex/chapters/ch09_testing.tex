\subsection{Testing Strategy}
Testing is layered (unit, integration, functional, non-functional, boundary, concurrency, live devices); the simulated transport makes tests deterministic, so a failure reproduces from its seed. The \NTests\ test cases were run completely \NRuns\ times. \input{generated/tests_summary.tex}

\subsection{Unit Testing}
Each module is tested alone: the packet format (47 tests), cost function and graph, Dijkstra with caching and \texttt{RESCUE\_\_}, gossip, discovery, the dedup set, priority queue, ACK tracker, store-and-forward bounds, AES-GCM, Ed25519, the SQLite log, relay and simulated transport.

\subsection{Integration Testing}
\texttt{test\_node} (28 tests) covers multi-hop sending, ACK, the message lifecycle, end-to-end encryption and signing, retry exhaustion, eviction and expiry; \texttt{test\_ack\_multihop} checks ACKs and retries across relays; \texttt{test\_api} and \texttt{test\_device\_api} drive the servers and engine together; \texttt{test\_lan\_transport} runs a three-node mesh over real TCP.

\subsection{Non-Functional Testing}
\label{sec:nonfunc}
\textbf{Reliability:} delivery at 0--50\,\% loss (Figure~\ref{fig:results}a). \textbf{Scalability:} 10 to 65 nodes (Table~\ref{tab:scale}). \textbf{Performance:} latency by priority (Section~\ref{sec:perfresults}), throughput and live latency (Table~\ref{tab:live}). \textbf{Availability:} 50 simulated recoveries and 8 live failovers. \textbf{Security:} relays never see plaintext; tampering, wrong keys, forged signatures and unknown signers are rejected. \textbf{Usability:} one 1.2\,s hold, plain-language status, optional voice input; no study with participants.

\subsection{Boundary and Invalid-Input Testing}
\label{sec:boundary}
Empty, header-only and truncated input; bad magic; out-of-range TTL and lengths; over-long paths and ids; wrong-length signatures and keys; ciphertext shorter than the nonce; a send to an unknown destination (held, not raised). \texttt{test\_robustness} feeds 3\,000 random and 1\,000 bit-flipped packets to the parser and 200 garbage buffers to a running node, which must reject them and keep working.

\subsection{Concurrency and Stress Testing}
\label{sec:stress}
200 simultaneous sends over two hops arrived exactly once with every ACK; 50 SOS and 50 routine messages from two senders arrived intact; a packet replayed five times was delivered once; throughput to 2\,000 sends and the congested priority scenario complete the stress tests.

\subsection{Limitations and Untested Scenarios}
\label{sec:limits}
No radio hardware (interference, fading, mobility untested); live timings on loopback only; no usability study; voice input checked with a stand-in recogniser, not real speech; browser checks run by hand; nothing above 65 nodes; relays do not retain; one pre-shared key and no external security review.
