# Contributing Guide

## Branch Naming

- main — tagged releases only
- develop — integration branch
- eature/<track>-<short-name> — new features
- ix/<short-name> — bug fixes
- docs/<short-name> — documentation changes
- 	est/<short-name> — test changes

## Commit Convention

Use Conventional Commits.

Examples:

- eat(routing): add link-quality term to cost function
- ix(reliability): reset ttl check before dedup
- 	est(sim): add high_loss scenario
- docs: update project plan
- chore: update dependencies

## Pull Requests

Every merge into develop should go through a pull request
reviewed by at least one other team member.
